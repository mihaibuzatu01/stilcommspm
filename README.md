CHestionar comunicare – versiune web mobile

1. Deschide index.html / chestionar_comunicare_mobile.html într-un browser pentru test.
2. Pentru publicare gratuită:
   - Netlify Drop: încarcă folderul/site-ul.
   - GitHub Pages: publică fișierul ca index.html într-un repository Pages.
3. QR-ul trebuie să indice URL-ul public primit după publicare.

Această versiune calculează local în browser scorurile A/T/C/E și desenează poligonul A→C→T→E→A.
Nu trimite și nu stochează răspunsurile nicăieri.
